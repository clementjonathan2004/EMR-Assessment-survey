# EMR Assessment Survey

## 1. Project Title

*Electronic Health Record (EHR) Usage Analysis Using Microsoft Excel*

## 2. Project Overview

This project analyzes survey data collected to assess the usage of Electronic Health Records (EHR) and the factors affecting their use.

The analysis was carried out using Microsoft Excel to examine respondents' categories, gender, age groups, frequency of EHR usage, challenges affecting EHR usage, and suggestions for improving EHR implementation.

An Excel dashboard was created to present the findings using charts and key metrics.

## 3. Problem Statement

Electronic Health Records are important for improving healthcare information management and supporting efficient healthcare service delivery.

However, factors such as high costs, poor infrastructure, staff resistance, and lack of training can affect the effective use of EHR systems.

This project analyzes survey responses to identify the level of EHR usage, the major challenges affecting usage, and suggestions that could support better EHR implementation.

## 4. Data Source

The data was collected through an *EHR assessment survey*.

The dataset contains responses from *81 respondents*, including healthcare workers and students.

The survey information was analyzed based on:

- Respondent category
- Gender
- Age group
- EHR usage frequency
- Challenges affecting EHR usage
- Suggestions for improving EHR usage

## 5. Methodology

The project was carried out using *Microsoft Excel* through the following steps:

1. Collected survey responses.
2. Organized the survey data for analysis.
3. Reviewed respondents' demographic information.
4. Categorized respondents by occupation/category.
5. Analyzed gender and age-group distribution.
6. Examined the frequency of EHR usage.
7. Identified the major challenges affecting EHR usage.
8. Analyzed respondents' suggestions for improving EHR implementation.
9. Summarized the results using key metrics.
10. Created an interactive Excel dashboard using charts and visualizations.

## 6. Key Insights

The analysis produced the following findings:

- A total of *81 respondents* participated in the survey.
- There were *50 male respondents* and *31 female respondents*.
- The respondents were grouped into *four age categories*: 15–20, 21–25, 26–30, and 30+.
- Students represented the larger respondent category, with approximately *52 respondents, while healthcare workers accounted for approximately **29 respondents*.
- The *Sometimes* category had the highest recorded EHR usage frequency at approximately *38 respondents*.
- *High cost* was identified as the biggest challenge affecting EHR usage, followed closely by *poor infrastructure* and *staff resistance*.
- *Adequate hardware provision* was the leading suggestion for improving EHR usage, followed by *reliable power supply* and a *standardized data entry process*.

## 7. Conclusion / Recommendations

### Conclusion

The EHR Usage Analysis shows that respondents experience several challenges that can affect the effective use of Electronic Health Records.

The findings highlight the importance of adequate infrastructure, hardware, reliable electricity, staff support, and proper data-entry procedures in improving EHR usage.

### Recommendations

Based on the findings, the following recommendations are made:

- Provide adequate hardware and equipment for EHR implementation.
- Improve infrastructure to support reliable EHR usage.
- Ensure a reliable power supply in healthcare facilities.
- Provide appropriate training to improve users' ability to work with EHR systems.
- Address staff resistance through proper communication, training, and support.
- Establish standardized data-entry procedures to improve consistency and data quality.
